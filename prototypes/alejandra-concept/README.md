# Alejandra concept demo

Demo visual aislada para evaluar a Alejandra como un centro de control operativo sereno.
No se integra con la aplicación existente, backend, Workers, permisos ni datos reales.

Abrir `index.html` localmente. Los selectores de empresa, obra y departamento cambian
únicamente datos simulados. Las acciones, filtros y estados son demostrativos; no se realizan
peticiones ni se guardan cambios. Incluye tema claro/oscuro y navegación compacta para móvil.
