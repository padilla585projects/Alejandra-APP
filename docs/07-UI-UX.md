# UI/UX

La PWA de campo y el panel de oficina comparten datos, pero no el mismo contexto de uso. La PWA prioriza acciones rápidas, conexión inestable, cámara/escaneo y claridad; el panel prioriza densidad de información, revisión y trazabilidad.

Principios: mostrar solo acciones permitidas, explicar estados y errores, conservar contexto de empresa/obra/departamento visible y no convertir una respuesta de IA en una acción irreversible sin control humano.

`PENDIENTE`: sistema de diseño, inventario de componentes, criterios de accesibilidad, flujos críticos y pruebas con usuarios.
