# Registro de ideas

Este directorio separa exploración de compromiso. Una idea no autoriza desarrollo ni despliegue.

Estados válidos: `Idea`, `Investigación`, `Aprobada`, `Planificada`, `En desarrollo`, `Finalizada`, `Descartada`.

Crear cada registro desde `IDEA-TEMPLATE.md`. Las ideas aprobadas deben enlazarse a una especificación, ADR o PR; las descartadas conservan el motivo.
