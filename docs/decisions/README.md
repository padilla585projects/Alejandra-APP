# ADR — Architecture Decision Records

Un ADR registra una decisión arquitectónica significativa y su motivo. Se numera secuencialmente (`ADR-0001-titulo.md`), se crea antes o junto al cambio y no se reescribe tras ser aceptado. Una decisión modificada se sustituye mediante otro ADR enlazado.

Estados válidos: `Propuesto`, `Aceptado`, `Rechazado`, `Sustituido`.

Crear desde `ADR-TEMPLATE.md`. El ADR debe enlazarse desde `PROJECT_STATE.md` si cambia la arquitectura vigente.
