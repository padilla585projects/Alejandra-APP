# Runbook — Incidencia

1. Clasificación: seguridad, disponibilidad, datos, IA, integración o `otro`.
2. Fecha/hora, responsable y alcance de usuarios/datos.
3. Contención inmediata sin destruir evidencia.
4. Diagnóstico, decisiones y comunicaciones registradas.
5. Recuperación, validación y seguimiento.
6. Causa raíz y acciones preventivas enlazadas a PR/ADR.
