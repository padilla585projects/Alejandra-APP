# Runbook — Despliegue

Propósito: promover una versión aprobada sin introducir cambios no revisados.

1. Responsable y aprobador: `PENDIENTE`.
2. Precondiciones: commit/artefacto identificado, CI verde, ADR/runbook aplicable, backup/mitigación de datos revisada.
3. Ejecución: pasos exactos a completar tras aprobar ADR-0001.
4. Validación: healthcheck, flujo crítico y observabilidad definidos.
5. Rollback: versión/artefacto anterior y responsable de decisión.
6. Evidencia: fecha, versión, resultado y enlaces.
