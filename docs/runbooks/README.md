# Runbooks

Los runbooks describen operaciones repetibles y seguras. No contienen secretos. Completar el tipo correspondiente antes de ejecutar una operación y enlazarlo desde la PR o incidencia.

- `DEPLOYMENT-TEMPLATE.md`: promoción a producción.
- `ROLLBACK-TEMPLATE.md`: reversión de una entrega o mitigación de datos.
- `INCIDENT-TEMPLATE.md`: respuesta a incidente.
- `RECOVERY-TEMPLATE.md`: recuperación de servicio, datos o archivos.
- `MAINTENANCE-TEMPLATE.md`: mantenimiento planificado.
- `UPDATE-TEMPLATE.md`: actualización de dependencia, plataforma o proveedor.
- `AUDIT-TEMPLATE.md`: auditoría técnica o de permisos.
