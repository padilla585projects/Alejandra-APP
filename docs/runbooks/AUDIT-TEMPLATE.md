# Runbook — Auditoría

1. Objetivo y alcance; declarar explícitamente recursos fuera de alcance.
2. Acceso autorizado, preferentemente solo lectura.
3. Evidencias a recolectar sin secretos ni datos personales innecesarios.
4. Hallazgos con severidad, impacto y recomendación.
5. Validación por responsable y enlaces a ADR/PR/incidencia.
6. Fecha de próxima revisión.
