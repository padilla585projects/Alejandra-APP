# Estándares de ingeniería

Los estándares normativos iniciales están en `../06-NORMAS-DE-INGENIERIA.md`. Este directorio reunirá normas específicas y verificables —por ejemplo, API, seguridad, pruebas, migraciones y accesibilidad— cuando sean aprobadas. Ningún estándar nuevo debe contradecir el manifiesto, un ADR aceptado o un runbook vigente.
